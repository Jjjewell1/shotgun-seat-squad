# Shotgun Seat Squad

A ComfyUI deployment for AI image generation.

Features:
- ComfyUI web UI for Stable Diffusion
- Client interface for remote control
- Generate icons and assets

Tech Stack:
- Node.js
- ComfyUI
- Custom generate-icons script

## Getting Started
```bash
npm install
npm run dev
```

## Deployment
Deploy to Coolify with Cloudflare Tunnel for external access.
